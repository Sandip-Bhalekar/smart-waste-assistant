# Dataset Report

This file is replaced with measured counts after `python scripts/inspect_dataset.py` is run on the downloaded dataset.

## Intended source

- Dataset: GARBAGE CLASSIFICATION 3 (Material Identification)
- Public mirror: https://huggingface.co/datasets/keremberke/garbage-object-detection
- Original listing: https://universe.roboflow.com/material-identification/garbage-classification-3
- License: CC BY 4.0
- Alternative considered: TACO (CC BY 4.0 annotations; mixed litter in context; 1,500 images; 60 classes; Flickr image URLs are often broken)

Run `python scripts/download_dataset.py` then `python scripts/inspect_dataset.py` to fill in image counts, object counts, and class frequencies from the files on disk.
